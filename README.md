# 💜 Lupin Music (Flutter Edition)

> **Luxury Dark Cyber Obsidian Music Streaming Application**  
> Written natively in Flutter for **Windows, macOS, Android, and iOS**.

Created by **Miraç Teksaslıoğlu** 👑

---

## ✨ Highlights & Features

- 🌌 **Obsidian & Neon Cyber Theme**: Deep `#090214` glassmorphic theme with `#ec4899` pink and `#a855f7` purple neon accents.
- 🎵 **YouTube Music InnerTube Engine**: Fast search, trending tracks, rich metadata, dynamic audio streaming via `just_audio` and `youtube_explode_dart`.
- 🎧 **Interactive Player & Scrubbing**: Instant 0ms seek bar, volume control with dynamic gradient fill, loop/shuffle modes.
- 🎛️ **Built-in Audio Equalizer**: Custom 5-band EQ visualization and preset controls.
- 🎮 **Discord Rich Presence (Desktop)**: Displays current song title, artist, and remaining time on Discord.
- 📱 **Multi-platform Native Performance**: Runs smoothly on Windows, macOS, Android, and iOS.

---

## 🚀 Building & Running

### Requirements
- Flutter SDK 3.0+
- Dart 3.0+

```bash
# Clone the repository
git clone https://github.com/mrcbrbn5361/LupinMusic-Flutter.git
cd LupinMusic-Flutter

# Get dependencies
flutter pub get

# Run on Desktop / Mobile
flutter run -d windows   # For Windows
flutter run -d macos     # For macOS
flutter run -d android   # For Android
flutter run -d ios       # For iOS
```
